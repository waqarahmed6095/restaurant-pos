Restaurant POS
==============

This is a restaurant-agnostic desktop point-of-sale app.

On the first launch, enter the restaurant name, address, contact details,
service charge, and optional logo/footer image paths. The profile is saved in
the user's application data directory under `Restaurant POS`.

The menu starts empty for a new installation. Use **Manage menu** after setup
to add the restaurant's categories, items, sizes, and prices. Menu data,
restaurant settings, PIN access, and sales data are persisted separately from
the installed application files.
